# Raw Data

The six source CSV files are packaged in `maven_fuzzy_factory_raw_data.zip`.

Extract the archive into this directory before running `sql/02_load_data.sql`. After extraction, this directory should contain:

```text
order_item_refunds.csv
order_items.csv
orders.csv
products.csv
website_pageviews.csv
website_sessions.csv
```

The archive is approximately 16 MB. The extracted files total approximately 99 MB.

Source and licensing information is available in [`../../DATA_SOURCE.md`](../../DATA_SOURCE.md).
