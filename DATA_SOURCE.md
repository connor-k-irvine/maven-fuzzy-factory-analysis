# Data Source and License

## Dataset

**Toy Store E-Commerce Database**  
Source: Maven Analytics Data Playground  
URL: https://mavenanalytics.io/data-playground/toy-store-e-commerce-database  
Dataset license: Public Domain

The data represents Maven Fuzzy Factory, a fictional online retailer selling teddy bears. It contains website sessions, pageviews, orders, order items, products, and refunds.

## Included source tables

| File | Description |
| --- | --- |
| `website_sessions.csv` | Website session and marketing-attribution records |
| `website_pageviews.csv` | Pageviews recorded within website sessions |
| `orders.csv` | Order-level revenue and cost data |
| `order_items.csv` | Product-level items included in orders |
| `order_item_refunds.csv` | Refund transactions linked to order items |
| `products.csv` | Product names and launch dates |

The raw files are stored together in `data/raw/maven_fuzzy_factory_raw_data.zip` to keep each GitHub file below the platform's standard size limit.
